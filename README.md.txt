# Vrinda Store Sales Dashboard

## Project Overview

An interactive sales dashboard created using Microsoft Excel to analyze sales and order data.

## Objectives

- Analyze monthly sales and order performance
- Understand customer demographics
- Compare sales by gender
- Identify top-performing states
- Analyze order status
- Understand sales and orders across different channels

## Tools & Skills

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Dashboard Development
- Business Analysis

## Analysis

The dashboard provides an interactive view of:

- Monthly sales and order trends
- Gender-wise sales
- Order status
- Top 5 states
- Age and gender distribution
- Sales/order contribution by channel

## Project Outcome

This project helped me practice transforming raw sales data into an interactive Excel dashboard and presenting information through business-focused data visualization.
